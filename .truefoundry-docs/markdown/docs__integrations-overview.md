# Integrations

> Overview of all supported integrations in the TrueFoundry platform.

TrueFoundry supports integration with different providers and their services.

You can find the details of each integrations on the following pages:

1. [AWS](/docs/integration-provider-aws) - Blob Storage (S3), Docker Registry (ECR), Secret Store (SSM), Cluster Integration (EKS)
2. [GCP](/docs/integration-provider-gcp) - Blob Storage (GCS), Docker Registry (GCR), Secret Store (GSM), Cluster Integration (GKE)
3. [Azure](/docs/integration-provider-azure) - Blob Storage (ABS), Docker Registry (ACR), Cluster Integration (AKS)
4. [Github](/docs/github-integration-set-up) - Source code repositories
5. [Gitlab](/docs/gitlab-integration-set-up) - Source code repositories
6. [Bitbucket](/docs/bitbucket-integration-set-up) - Source code repositories
7. [Azure Repos](/docs/azure-repos-integration-set-up) - Source code repositories
8. **DockerHub** - Docker Registry
9. **JFrog** - Docker Registry
10. **Quay** - Docker Registry
11. **Slack** - Notification Channel
12. **TTL** - Docker Registry

To integrate any of the above services, you simply need to add your provider account details and add the available integrations for the same. Let's try adding a Docker Registry from DockerHub to learn how this works:
