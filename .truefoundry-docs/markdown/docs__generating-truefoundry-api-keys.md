# Generating TrueFoundry API Keys

> Create and manage Personal Access Tokens and Virtual Accounts for programmatic TrueFoundry platform access.

TrueFoundry API Keys allow you to programmatically interact and perform actions on the TrueFoundry platform either using the [CLI / Python SDK](/docs/setup-cli) or [HTTP API](/docs/truefoundry_sdk/index) . Additionally they also allow you to access models via the [AI Gateway](/docs/ai-gateway).

<Info>
  This API Key can be provided to CLI / Python SDK via the `TFY_API_KEY` environment variable
</Info>

There are two types of API Keys

* [Personal Access Tokens](https://www.truefoundry.com/docs/ai-gateway/authentication#personal-access-token-pat)
* [Virtual Accounts](https://www.truefoundry.com/docs/ai-gateway/authentication#virtual-account-token-vat)
