# Prompt Management

> Learn how to create, test, save, and version your prompts using TrueFoundry's AI Gateway for optimised AI interactions.

Truefoundry's Prompt Management allows you to create, test, save, and version your prompts.

Truefoundry's LLM Playground is your space for experimenting, testing, and perfecting prompts before deploying them to production. Explore different models, test parameters, review completions, and fine-tune your prompt engineering strategy in a safe environment.

This section is now split into following pages:

* [Playground](/docs/ai-gateway/prompt-playground): Create prompts in the Playground, save/load templates, and configure guardrails, routing, structured output, MCP servers, and variables.
* [Prompt Versioning](/docs/ai-gateway/prompt-versioning): Understand version history, browse the Prompt Registry, and load specific versions.
* [Using Prompts](/docs/ai-gateway/using-prompts): Use prompts via the API (server-side rendering) or SDK (client-side rendering).
