# ارزیابی فارسی RAG

این مجموعه، کیفیت بازیابی، پاسخ مستند، امتناع، زبان پاسخ و ارجاع را روی محتوای فارسی و چند پرسش انگلیسی می‌سنجد. اجرای موفق باید به حداقل‌های پروفایل `rag-v3-fa-bge-m3` برسد: بازیابی و پاسخ مستند ۸۵٪، امتناع ۹۰٪ و اعتبار فنی ارجاع برابر ۱۰۰٪.

## پیش‌نیاز

1. در محیط اختصاصی سازمان آزمایشی یک پایگاه دانش بسازید.
2. فایل `corpus/managed-rag-fa.txt` را با عنوان «راهنمای ارزیابی فارسی گدارAI» بارگذاری کنید و تا وضعیت `ready` منتظر بمانید.
3. یک چت‌بات عمومی با سیاست زبان «هم‌زبان با پرسش» و فرهنگ `fa-IR` بسازید، پایگاه دانش را به آن متصل کنید و نسخه را منتشر کنید.
4. شناسه پایگاه دانش و `public_id` چت‌بات را در متغیرهای نگاشت قرار دهید.

## اجرا

از مسیر `services/rag` فرمان زیر را اجرا کنید:

```powershell
$env:RAG_EVAL_BASE_URL = "https://api.example.com"
$env:RAG_EVAL_TOKEN = "<tenant-api-token>"
$env:RAG_EVAL_KB_MAP = '{"persian-culture-fixture":"<knowledge-base-uuid>"}'
$env:RAG_EVAL_BOT_MAP = '{"persian-culture-bot":"<public-bot-id>"}'
go run ./cmd/fa-eval
```

خروجی فقط سنجه‌ها و شناسه آزمون‌های ناموفق را نشان می‌دهد و متن سند، پرسش یا پاسخ را ثبت نمی‌کند. کد خروجی غیرصفر یعنی حداقل یکی از معیارهای انتشار برآورده نشده است.
