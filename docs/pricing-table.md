# جدول صندلی‌ها و قابلیت‌ها

گدارAI پلن ندارد. همه‌ی قابلیت‌ها برای همه‌ی سازمان‌ها در دسترس است و هزینه فقط از دو جا می‌آید:

- **صندلی‌های پولی** (Pro و Max) برای اعتبار شخصی اعضا در GodarChat. پرداخت صندلی‌های پولی همان **اشتراک** است.
- **بسته‌های اعتبار** برای استخر مشترک سازمان که API، کلیدها، triggerها و گاردریل‌ها از آن مصرف می‌کنند.

جزئیات قواعد در [PRD صندلی‌ها و اعتبار شخصی](PRD%20صندلی‌ها%20و%20اعتبار%20شخصی%20گدارAI.md) و [PRD چارچوب قیمت‌گذاری کردیتی](PRD%20چارچوب%20قیمتگذاری%20کردیتی%20گدارAI.md) آمده است.

## صندلی‌ها

| | رایگان | Pro | Max |
|---|---|---|---|
| اعتبار شخصی | ۵۰۰، یک‌بار در عمر عضو در سازمان | ۲,۰۰۰ در ماه | ۱۰,۰۰۰ در ماه |
| تعداد | تا ۵ صندلی در هر سازمان | نامحدود (خرید) | نامحدود (خرید) |
| دسترسی به استخر سازمان | ندارد | دارد، تا سقف شخصی | دارد، تا سقف شخصی |
| قیمت (تومان در ماه، بدون مالیات) | رایگان | ۲,۲۵۰,۰۰۰ | ۱۱,۲۵۰,۰۰۰ |
| قابلیت‌ها | همه | همه | همه |

- قیمت صندلی‌ها ثابت است و اعتبارشان برای مارک‌آپ حدود ۱۰۰٪ روی هزینه‌ی provider تعیین شده است (۱,۱۲۵ تومان برای هر اعتبار صندلی). پشتیبانی قیمت هر صندلی را در support-admin رند تعیین می‌کند و فرمول قیمت فهرست فقط پیشنهاد است؛ جزئیات و محاسبه‌ی حاشیه در [PRD صندلی‌ها](PRD%20صندلی‌ها%20و%20اعتبار%20شخصی%20گدارAI.md) آمده است.
- عددهای «تعداد کار در ماه» در سایت برای انجام فقط یکی از کارهاست و با هم جمع نمی‌شوند.
- قیمت فهرست اعتبار از `credit_price_revisions` می‌آید و در `/pricing/changelog` منتشر می‌شود. پشتیبانی آن را با پیشنهاد سیاست ارزی یا دستی (Credits ← Set price) تغییر می‌دهد؛ قیمت، اعتبار و تخفیف هر صندلی در Credits ← Member seats تنظیم می‌شود.
- دوره‌ی آزمایشی وجود ندارد؛ صندلی‌های رایگان جای آن را گرفته‌اند.

## اشتراک (صندلی‌های پولی)

| موضوع | قاعده |
|---|---|
| شروع | با خرید اولین صندلی پولی. دوره (ماهانه یا سالانه) همان‌جا انتخاب می‌شود. |
| صندلی‌های بعدی | هم‌دوره با اشتراک، به نسبت روزهای باقی‌مانده. |
| پرداخت | پیش‌پرداخت از درگاه؛ کسر خودکار و تمدید خودکار ندارد. |
| تمدید | از ۷ روز مانده به پایان دوره تا پایان دوره. |
| انقضا | فقط صندلی‌های پولی غیرفعال می‌شوند و اعضایشان «بدون صندلی» می‌شوند. صندلی‌های رایگان، اعتبار بسته‌ها و API کار می‌کنند. |

## قابلیت‌ها (برای همه‌ی سازمان‌ها)

| حوزه | قابلیت‌ها |
|---|---|
| AI Gateway | API یکسان برای بیش از ۱۲۰۰ مدل، مدل مجازی، محیط تست Live، کش ساده و معنایی (Semantic Caching) |
| کنترل و نظارت | توزیع بار وزنی، مسیریابی بر مبنای سرعت و اولویت، مسیر جایگزین هنگام خطا، قانون‌های بودجه و نرخ درخواست |
| مشاهده‌پذیری | ثبت وقایع، Tracing، فراداده‌ی سفارشی و فیلتر روی آن، قیمت‌گذاری سفارشی LLM، گزارش‌های عملیاتی و هزینه‌ای، هشدارها، خروجی OpenTelemetry |
| مدیریت پرامپت | قالب‌های نامحدود، نسخه‌بندی پرامپت و متغیرها |
| حفاظت هوشمند | اتصال سرویس‌دهندگان ثالث، وب‌هوک اختصاصی |
| امنیت و احراز هویت | کلید دسترسی شخصی و مجازی، RBAC، SSO، مدیریت تیم‌ها، ثبت وقایع مدیریتی |
| استقرار | SaaS؛ استقرار در محل یا VPC با قرارداد جداگانه |
| پشتیبانی | پشتیبانی محصول؛ آنبوردینگ اختصاصی و SLA سازمانی با قرارداد جداگانه |
