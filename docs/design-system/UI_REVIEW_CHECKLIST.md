# UI Review Checklist

Before completing any UI task, verify:

- [ ] Existing reusable components were checked first.
- [ ] Semantic tokens are used instead of raw colors.
- [ ] No unnecessary arbitrary Tailwind values were introduced.
- [ ] Page spacing follows the standard layout system.
- [ ] Forms follow the standard form pattern.
- [ ] Tables follow the standard table pattern.
- [ ] Empty/loading/error states are handled.
- [ ] RTL behavior is acceptable.
- [ ] Responsive behavior is acceptable.
- [ ] Accessibility basics are respected.
- [ ] New reusable patterns are documented.
- [ ] Design system playground was updated if needed.
