## قواعد نگه‌داری

- فایل اصلی با بالاترین کیفیت موجود ذخیره شود.
- فرمت اصلی تصویر تغییر نکند؛ اگر منبع WebP یا JPEG بود، پسوند Manifest نیز همان‌جا اصلاح شود.
- تصویر Crop، Upscale، فشرده یا رنگ‌پردازی مجدد نشود.
- برای هر فایل، نسبت و ابعاد واقعی پس از دریافت به جدول اضافه شود.
- نسخه‌های بازطراحی‌شده یا تولید مجدد با پسوند `-recreated` از اصل متمایز شوند.
- تصویر تولید مجدد نباید جای فایل اصلی گفت‌وگو را بگیرد.
