# پرامپت ۱۹: درگاه MCP `/features/mcp-gateway`

اول `apps/website/docs/site-architecture/prompts/_shared-brief.md` را کامل بخوان. پرامپت‌های `00`، `01`، `12` و `16` باید اجرا شده باشند.

## نقش و هدف

تو طراح محصول و مهندس فرانت‌اند هستی. درگاه MCP لایهٔ فنی پشت «اتصال‌ها»ی فضای کاری است و صفحهٔ فعلی (۱۲۵۶ خط) برای تیم فنی‌ای نوشته شده که ایجنت را به ابزار واقعی وصل می‌کند. بازطراحی روی سیستم جدید، کوتاه‌تر، با پیوند دوطرفه به `/integrations` (نگاه مدیر) و حفظ عمق فنی.

## فایل‌های مخصوص

`app/pages/features/MCPGateway.tsx`، `app/pages/Integrations.tsx` (از پرامپت ۱۲).

## بخش‌ها و پیش‌نویس متن

1. **PageHero** + ProductWindow (فهرست سرورها و ابزارها): «یک مسیر مشترک برای همهٔ سرورهای MCP.» · «سرورها و ابزارها را یک جا ثبت کنید، دسترسی را تا سطح ابزار بدهید و هر فراخوانی را ببینید.»
2. **چهار کنترل پایه** (PillarGrid چهارتایی خنثی، از محتوای فعلی): احراز هویت متناسب با هر سرور · فهرست مرکزی · دسترسی سطح سرور و ابزار · مشاهده‌پذیری فراخوانی.
3. **اشتراک ابزار بدون افشای اعتبارنامه** (FeatureRow، تیند govern).
4. **اجرای سیاست پیش از فراخوانی** (FeatureRow، تیند guard) — فقط سیاست‌هایی که امروز اجرا می‌شوند؛ «تأیید انسانی» ادعا نشود.
5. **تحلیل مصرف و عملکرد** (FeatureRow، تیند observe).
6. پیوند به `/integrations`: «فهرست اتصال‌های فضای کاری».
7. **ClosingBand**.
