# پرامپت ۱۶: درگاه مدل‌های زبانی `/features/ai-gateway` (هاب محصول دوم)

اول `apps/website/docs/site-architecture/prompts/_shared-brief.md` را کامل بخوان. پرامپت‌های `00` و `01` باید اجرا شده باشند.

## نقش و هدف

تو طراح محصول و مهندس فرانت‌اند هستی. «درگاه مدل‌های زبانی» محصول دوم و هم‌وزن گدارAI است و این صفحه هاب آن برای توسعه‌دهنده و تیم محصول است: یک نشانی سازگار با OpenAI برای ۱۲۰۰+ مدل از ۲۱ ارائه‌دهنده، با کلید، مسیریابی، حافظهٔ نهان و گزارش. صفحهٔ فعلی (۱۰۰۹ خط) محتوای خوبی دارد ولی رنگ خام و داشبورد ساختگی دارد. محتوای ایجنت توسعه‌دهنده از `/features/agents` هم به این‌جا می‌آید (بخش `#agents`).

## فایل‌های مخصوص

`app/pages/features/AIGateway.tsx`، `app/pages/features/Agents.tsx` (منبع بخش ایجنت)، `app/(site)/features/ai-gateway/page.tsx`، بخش‌های «درگاه، مدل‌ها و اتصال» و «سرآیندها» در `docs/content-glossary.md`.

توسعه‌دهنده، تیم محصول · «یک نشانی برای همهٔ مدل‌ها، با کلید و هزینهٔ کنترل‌شده؟» · 🔵 و 🟡.

## بخش‌ها و پیش‌نویس متن

1. **PageHero** + ProductWindow که قطعه‌کد اتصال را نشان می‌دهد (`base_url` و `model` با SDK رسمی OpenAI؛ کد LTR، با رنگ‌آمیزی سادهٔ توکنی).
   - تیتر: «یک نشانی برای همهٔ مدل‌ها.»
   - متن: «API سازگار با OpenAI برای بیش از ۱۲۰۰ مدل از ۲۱ ارائه‌دهنده. کلید، مسیریابی، هزینه و گزارش در همان مسیر.»
   - دکمه‌ها: «۱۵ روز رایگان شروع کنید» · «مستندات» (`/docs`)
2. **اجزای اتصال عملیاتی** (PillarGrid سه‌تایی خنثی): یک API · مدل مجازی · کلید جدا برای انسان و سرویس.
3. **مسیریابی با مدل مجازی** (FeatureRow): اولویتی و وزنی، مسیر جایگزین هنگام خطا.
4. **حافظهٔ نهان** (FeatureRow، تیند cost) ← `/features/cost-control`
5. **کلیدها و بودجه** (FeatureRow): PAT و VAT، سقف برای هر کلید.
6. **گزارش و رد درخواست** (FeatureRow، تیند observe) ← `/features/observability`
7. **`#agents` ایجنت خودتان را وصل کنید** (FeatureRow): خلاصهٔ محتوای فعلی `Agents.tsx`: مستقل از چارچوب، تلاش دوباره و مسیر جایگزین، رد درخواست برای هر فراخوانی.
8. **قابلیت‌های تکمیلی** (فهرست فشرده): پردازش دسته‌ای و موارد دیگر صفحهٔ فعلی.
9. **ابزارهای درگاه** (کارت پیوندی): کشف مدل‌ها · رجیستری پرامپت · درگاه MCP · داشبورد · کاتالوگ ↗.
10. **مقایسه** (دو پیوند): «گدارAI و LiteLLM» · «گدارAI و Portkey».
11. **ClosingBand**: «اولین درخواست را امروز بفرستید.» · «۱۵ روز رایگان شروع کنید» · «مستندات».
