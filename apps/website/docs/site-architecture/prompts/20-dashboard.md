# پرامپت ۲۰: داشبورد `/dashboard`

اول `apps/website/docs/site-architecture/prompts/_shared-brief.md` را کامل بخوان. پرامپت‌های `00`، `01` و `06` باید اجرا شده باشند.

## نقش و هدف

تو مهندس فرانت‌اند هستی. `/dashboard` صفحهٔ بازاریابی «نمای کلی داشبورد» است (۲۰۷ خط) و با `/features/observability` همپوشانی دارد. مسیر حفظ می‌شود؛ صفحه کوتاه و توسعه‌دهنده‌محور می‌شود: سنجه‌های مدل (تأخیر، خطا، توکن) و پیوند به مشاهده‌پذیری برای نگاه مدیر.

## فایل‌های مخصوص

`app/pages/Dashboard.tsx`، `app/(site)/dashboard/page.tsx`، `components/charts/*`، `app/pages/features/Observability.tsx` (پس از پرامپت ۰۶).

## بخش‌ها

1. **PageHero** + اسکرین‌شات داشبورد: «سنجه‌های هر مدل، یک جا.» · «تأخیر، خطا و مصرف توکن هر مدل و هر کلید را ببینید.»
2. دو یا سه FeatureRow از محتوای فعلی، تیند observe.
3. پیوند: «مصرف و هزینه به تفکیک تیم» ← `/features/observability`.
4. **ClosingBand**.

نمودارها با رنگ توکن و برچسب «نمونه»، یا جایگزین با اسکرین‌شات.

## معیار پذیرش

طبق بریف مشترک. هیچ بخشی تکرار کلمه‌به‌کلمهٔ `/features/observability` نباشد.
