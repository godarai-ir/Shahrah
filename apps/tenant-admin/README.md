# Tenant Admin

Tenant-facing Next.js application for Shahrah customers.

## Purpose

- API key management
- usage dashboards
- billing and wallet views
- model and routing settings

## Commands

Run from the repository root:

```bash
pnpm --filter @shahrah/tenant-admin dev
pnpm --filter @shahrah/tenant-admin build
pnpm --filter @shahrah/tenant-admin lint
```
