# Docs App

Docusaurus site for Shahrah documentation.

## Purpose

- developer onboarding
- API reference
- SDK guides
- billing and platform docs

The Docusaurus blog is intentionally disabled because Shahrah uses the separate Astro app in `apps/blog`.

## Commands

Run from the repository root:

```bash
pnpm --filter @shahrah/docs dev
pnpm --filter @shahrah/docs build
pnpm --filter @shahrah/docs lint
```
