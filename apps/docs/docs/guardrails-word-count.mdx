# محدودیت تعداد واژه

`word_count` تعداد واژه‌های هر متن را بررسی می‌کند و متن خارج از بازه را نامعتبر می‌داند.

## چه زمانی استفاده کنیم؟

- محدودکردن طول پرامپت کاربر
- الزام پاسخ کوتاه یا حداقل طول پاسخ
- کنترل تقریبی حجم متن مستقل از توکنایزر (tokenizer) مدل

## رفتار اجرایی

این نوع فقط از `operation: "validate"` پشتیبانی می‌کند. توالی‌های حرف و عدد به‌عنوان واژه شمرده می‌شوند و `_` و `-` داخل واژه جداکننده نیستند. بنابراین `hello-world` و `customer_id` هر کدام یک واژه حساب می‌شوند.

در یک رشته گفتگو، هر پیام به‌صورت جداگانه بررسی می‌شود؛ شمارش بین چند پیام با هم جمع نمی‌شود.

## تنظیمات

| فیلد | نوع | اجباری | توضیح |
| --- | --- | --- | --- |
| `min` | `integer` | حداقل یکی از `min` یا `max` | حداقل تعداد مجاز؛ صفر یا بیشتر. |
| `max` | `integer` | حداقل یکی از `min` یا `max` | حداکثر تعداد مجاز؛ صفر یا بیشتر. |

## نمونه تعریف

```json
{
  "slug": "prompt-word-limit",
  "name": "Prompt word limit",
  "type": "word_count",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "max": 500
  }
}
```

## نمونه استفاده

```text
x-godarai-guardrails: {"llm_input_guardrails":["guardrails/prompt-word-limit"]}
```

## محدودیت‌ها

- این شمارش ارتباطی با توکن‌های مدل ندارد و برای محاسبه هزینه یا context window مناسب نیست.
- زبان‌هایی که مرز واژه را با فاصله مشخص نمی‌کنند ممکن است شمارش دقیقی نداشته باشند.
