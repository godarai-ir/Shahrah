# تعداد کلمه

گاردریل `word_count` تعداد کلمه‌های هر متن را بررسی می‌کند و اگر متن بیرون از بازه مجاز باشد، نتیجه بررسی را ناموفق می‌کند. این نوع برای کنترل تقریبی حجم متن مناسب است، به‌ویژه وقتی نمی‌خواهید کاربر یا مدل متن بسیار بلند تولید کند.

:::info
تعداد کلمه با تعداد توکن مدل یکی نیست. این گاردریل برای تجربه کاربری و سیاست محتوایی مناسب است، نه برای محاسبه دقیق هزینه یا ظرفیت پنجره زمینه.
:::

## چه زمانی استفاده کنید؟

از `word_count` برای این کارها استفاده کنید:

- محدودکردن طول ورودی کاربر.
- الزام پاسخ مدل به حداقل یا حداکثر تعداد کلمه.
- کنترل تقریبی حجم متن، بدون وابستگی به توکنایزر مدل.

اگر محدودیت شما باید دقیق‌تر از کلمه باشد، از [تعداد کاراکتر](/guardrails-character-count) استفاده کنید. اگر خوانایی پاسخ کوتاه مهم‌تر از طول دقیق است، [تعداد جمله](/guardrails-sentence-count) مناسب‌تر است.

## رفتار اجرایی

این نوع فقط از «اعتبارسنجی» (`operation: "validate"`) پشتیبانی می‌کند. توالی‌های حرف و عدد به‌عنوان کلمه شمرده می‌شوند. `_` و `-` داخل کلمه جداکننده نیستند؛ بنابراین `hello-world` و `customer_id` هر کدام یک کلمه حساب می‌شوند.

هر پیام یا بخش متنی جداگانه بررسی می‌شود. شمارش چند پیام با هم جمع نمی‌شود.

## تنظیمات

| عنوان UI | مقدار API | توضیح |
| --- | --- | --- |
| حداقل | `min` | حداقل تعداد کلمه مجاز. مقدار باید صفر یا بیشتر باشد. |
| حداکثر | `max` | حداکثر تعداد کلمه مجاز. مقدار باید صفر یا بیشتر باشد. |

باید دست‌کم یکی از «حداقل» یا «حداکثر» را وارد کنید. اگر هر دو را وارد می‌کنید، حداقل باید کوچک‌تر یا برابر حداکثر باشد.

:::tip
برای ورودی کاربر، ابتدا این گاردریل را با «عبور همراه با نشانه‌گذاری» فعال کنید و گزارش رخدادها را ببینید. بعد از شناخت الگوی استفاده واقعی، می‌توانید «عدم عبور و لاگ» را برای مسیرهای حساس‌تر فعال کنید.
:::

## نمونه تعریف

```json
{
  "slug": "prompt-word-limit",
  "name": "Prompt word limit",
  "type": "word_count",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "max": 500
  }
}
```

## نمونه استفاده

برای کنترل ورودی مدل:

```text
x-godarai-guardrails: {"llm_input_guardrails":["guardrails/prompt-word-limit"]}
```

## بررسی نتیجه

اگر تعداد کلمه بیرون از بازه باشد، علت `word count is outside allowed range` ثبت می‌شود.

| شیوه اعمال | رفتار |
| --- | --- |
| عدم عبور و لاگ | مسیر متوقف می‌شود. |
| عبور همراه با نشانه‌گذاری | مسیر ادامه پیدا می‌کند و وضعیت `flagged` ثبت می‌شود. |

## محدودیت‌ها

- تعداد کلمه با تعداد توکن مدل یکی نیست و برای محاسبه هزینه یا پنجره زمینه مناسب نیست.
- زبان‌هایی که مرز کلمه را با فاصله مشخص نمی‌کنند، ممکن است شمارش دقیقی نداشته باشند.
- متن‌هایی با شناسه‌ها، مسیر فایل یا کلمات خط‌دار ممکن است کمتر از انتظار شمرده شوند.
- گاردریل خروجی با پاسخ جریانی پشتیبانی نمی‌شود.

## پرسش‌های پرتکرار

### آیا متن فارسی درست شمرده می‌شود؟

در متن فارسی که کلمه‌ها با فاصله جدا شده‌اند، شمارش معمولاً قابل استفاده است. نیم‌فاصله و قالب‌های خاص ممکن است روی شمارش اثر بگذارند.

### اگر فقط سقف دقیق طول مهم باشد، چه کنم؟

از [تعداد کاراکتر](/guardrails-character-count) استفاده کنید؛ چون فاصله، خط جدید و علائم را هم می‌شمارد و برای محدودیت طول دقیق‌تر است.

## گام بعدی

- برای محدودیت جمله، [تعداد جمله](/guardrails-sentence-count) را ببینید.
- برای سقف دقیق طول متن، [تعداد کاراکتر](/guardrails-character-count) را بخوانید.
