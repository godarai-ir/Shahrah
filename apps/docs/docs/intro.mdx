# Shahrah Documentation

Shahrah is a multi-tenant LLM gateway platform designed around:

- OpenAI-compatible APIs
- tenant isolation by subdomain
- Rial wallet billing for the Iranian market
- an Iran-Europe tunnel for provider access

This docs app is the home for product documentation, API reference, SDK guides,
and operational concepts.
