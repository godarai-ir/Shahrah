# مستندات گدارAI

گدارAI یک پلتفرم چندمستاجری برای گیت‌وی مدل‌های زبانی است که بر این اصول طراحی شده است:

- OpenAI-compatible APIs
- tenant isolation by subdomain
- Rial wallet billing for the Iranian market
- an Iran-Europe tunnel for provider access

این اپلیکیشن docs خانه مستندات محصول، مرجع API، راهنماهای SDK
و مفاهیم عملیاتی است.

## بخش‌های اصلی

- شروع کار
- مفاهیم اصلی
- مرجع API
- SDKها
- صورتحساب
- عیب‌یابی

## اپلیکیشن‌های مرتبط

- `apps/docs`: documentation site
- `apps/blog`: marketing and technical blog
- `apps/tenant-admin`: tenant-facing dashboard
- `apps/model-discovery-web`: public model and provider catalog
- `apps/support-admin`: internal support and privileged administration dashboard
