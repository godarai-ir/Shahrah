- متنی و مکالمه‌ای

- تصویر
- صوت
- کنترل و پردازش

## FAQ

### از کدام API شروع کنم؟

برای بیشتر integrationهای متنی، `Chat Completions` نقطه شروع پیش‌فرض بهتری است.

### آیا همه APIهای این بخش همین حالا production-ready هستند؟

خیر. بعضی صفحات وضعیت فعلی implementation را شفاف گفته‌اند و هنوز از جنس capability برنامه‌ریزی‌شده هستند.

### اگر فقط یک مدل یا یک provider دارم، باز هم این ساختار به درد می‌خورد؟

بله. حتی در این حالت هم دسته‌بندی APIها کمک می‌کند endpoint مناسب را سریع‌تر پیدا کنید.
