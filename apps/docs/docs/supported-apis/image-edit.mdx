# Image Edit

`Image Edit` برای تغییر هدفمند یک تصویر موجود استفاده می‌شود. در این مسیر، تصویر ورودی را همراه پرامپت می‌فرستید و مدل نسخه ویرایش‌شده را برمی‌گرداند.

```text
POST /v1/images/edits
```

:::info
اگر هیچ تصویر اولیه‌ای ندارید، از [Image Generation](/supported-apis/image-generation) شروع کنید. اگر می‌خواهید فقط نسخه‌های مشابه یک تصویر بسازید و نه تغییر دقیق روی آن، [Image Variation](/supported-apis/image-variation) انتخاب بهتری است.
:::

## چه زمانی استفاده کنیم؟

از `Image Edit` استفاده کنید وقتی می‌خواهید:

- بخشی از تصویر را روشن‌تر، ساده‌تر یا تمیزتر کنید.
- پس‌زمینه، رنگ یا سبک تصویر را تغییر دهید.
- یک شیء مشخص را اضافه یا حذف کنید، اگر مدل پشتیبانی کند.
- با `mask` ناحیه ویرایش را محدود کنید.

ویرایش تصویر برای کنترل دقیق‌تر از تولید تصویر است، اما نتیجه همچنان به مدل، کیفیت تصویر ورودی و دقت پرامپت وابسته است.

## شروع سریع با فایل

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_GODARAI_TOKEN",
    base_url="https://YOUR_WORKSPACE.godarai.ir/v1",
)

with open("sample.png", "rb") as image:
    response = client.images.edit(
        model="openai:default:gpt-image-1",
        image=image,
        prompt="پس‌زمینه تصویر را ساده‌تر و روشن‌تر کن، اما سوژه اصلی را تغییر نده.",
        size="1024x1024",
        response_format="url",
    )

print(response.data[0].url)
```

این روش معمولاً با `multipart/form-data` ارسال می‌شود و برای فایل واقعی انتخاب طبیعی‌تری است.

## ارسال با JSON

در بعضی مدل‌ها یا مسیرهای سازگار، می‌توانید نشانی تصویر را در JSON بفرستید:

```json
{
  "model": "xai:default:grok-imagine-image",
  "prompt": "نور تصویر را طبیعی‌تر کن.",
  "image": {
    "type": "image_url",
    "url": "https://YOUR_WORKSPACE.godarai.ir/assets/input-image.png"
  },
  "response_format": "url"
}
```

:::warning
نشانی تصویر باید برای ارائه‌دهنده مدل قابل دسترس باشد. اگر فایل پشت شبکه خصوصی، نشست کاربری یا لینک موقت کوتاه‌عمر باشد، درخواست ممکن است خطا بدهد یا نتیجه ناپایدار شود.
:::

## `mask` چه زمانی لازم است؟

`mask` محدوده‌ای را مشخص می‌کند که مدل اجازه ویرایش آن را دارد. اگر فقط بخش کوچکی از تصویر باید تغییر کند، استفاده از `mask` نتیجه را قابل پیش‌بینی‌تر می‌کند.

نمونه کاربرد:

- تغییر رنگ یک شیء خاص.
- حذف یک بخش مزاحم.
- جایگزینی پس‌زمینه بدون تغییر سوژه اصلی.

:::tip
اگر ویرایش باید دقیق باشد، پرامپت را موضعی بنویسید: بگویید کدام بخش تغییر کند و کدام بخش دست‌نخورده بماند.
:::

## فیلدهای رایج

| فیلد | کاربرد |
| --- | --- |
| `model` | شناسه مدل تصویری مجاز. |
| `image` | تصویر ورودی؛ فایل، نشانی یا ساختار وابسته به مدل. |
| `prompt` | توضیح تغییر مورد نظر. |
| `mask` | ناحیه مجاز برای ویرایش. |
| `size` | اندازه خروجی، اگر مدل پشتیبانی کند. |
| `response_format` | `url` یا `b64_json`، بسته به مدل. |

## خروجی

پاسخ معمولاً شبیه خروجی تولید تصویر است:

```json
{
  "created": 1720000000,
  "data": [
    {
      "url": "https://YOUR_WORKSPACE.godarai.ir/assets/edited-image.png",
      "revised_prompt": "..."
    }
  ]
}
```

یا ممکن است `b64_json` برگردد. اپلیکیشن شما باید برای هر دو حالت آماده باشد، مگر اینکه مدل و تنظیمات محیط شما فقط یک فرمت را تضمین کنند.

## حریم خصوصی فایل ورودی

تصویر ورودی ممکن است شامل چهره، سند، آدرس، اطلاعات محصول یا داده مشتری باشد. پیش از ارسال تصویر:

- داده حساس را حذف یا ماسک کنید.
- فقط فایل لازم را بفرستید.
- دسترسی به خروجی ویرایش‌شده را محدود کنید.
- نگهداری خروجی در storage خودتان را با سیاست داخلی هماهنگ کنید.

## هزینه و پایش

در گزارش رخدادها و رد درخواست، جزئیات حساس تصویر و base64 کامل نباید معیار عیب‌یابی شما باشد. به جای آن، از شناسه رد درخواست، وضعیت پاسخ، اندازه تقریبی فایل، تعداد خروجی و هزینه ثبت‌شده استفاده کنید.

## خطاهای رایج

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| `model is required` | مدل ارسال نشده است. | شناسه مدل تصویری مجاز را وارد کنید. |
| `Model access denied or unsupported for image generation` | مدل برای تصویر مجاز نیست. | مدل نوع `image_generation` انتخاب کنید. |
| خطای `unsupported content type` | نوع بدنه درخواست پشتیبانی نمی‌شود. | از `application/json` یا `multipart/form-data` استفاده کنید. |
| خروجی با خواسته شما فاصله دارد | پرامپت یا ماسک مبهم است. | پرامپت را موضعی‌تر کنید و در صورت نیاز `mask` بدهید. |

## جمع‌بندی

`Image Edit` برای تغییر هدفمند تصویر موجود است. با فایل تمیز، پرامپت دقیق، مدل تصویری مجاز و بررسی هزینه/رخداد، می‌توانید ویرایش تصویر را در محصول خود قابل کنترل‌تر پیاده کنید.
