# Text to Speech

`Text to Speech` متن را به فایل صوتی تبدیل می‌کند. این API برای محصول‌هایی مناسب است که می‌خواهند پاسخ‌ها، اعلان‌ها، راهنماها یا محتوای آموزشی را به شکل گفتار تولید کنند.

```text
POST /v1/audio/speech
```

:::info
فعال‌بودن `Text to Speech` به نسخه و تنظیمات محیط گدارAI شما بستگی دارد. اگر مسیر صوتی در محیط شما فعال نیست، این صفحه را به‌عنوان قرارداد هدف و راهنمای طراحی مصرف در نظر بگیرید.
:::

## چه زمانی استفاده کنیم؟

از `Text to Speech` استفاده کنید وقتی می‌خواهید:

- پاسخ متنی مدل را برای کاربر بخوانید.
- اعلان صوتی یا راهنمای صوتی بسازید.
- محتوای آموزشی یا پشتیبانی را به صوت تبدیل کنید.
- تجربه دسترس‌پذیرتری برای کاربران کم‌بینا یا رانندگان فراهم کنید.

اگر ورودی شما فایل صوتی است و خروجی متن می‌خواهید، [Speech to Text](/supported-apis/speech-to-text) را ببینید.

مدل و صدای انتخابی باید در محیط شما فعال و مجاز باشند.

## فیلدهای رایج

| فیلد | کاربرد |
| --- | --- |
| `model` | شناسه مدل تولید گفتار. |
| `input` | متن ورودی برای خوانده‌شدن. |
| `voice` | صدای خروجی، اگر مدل چند صدا داشته باشد. |
| `response_format` | فرمت فایل خروجی، مثل `mp3` یا `wav` بسته به مدل. |
| `speed` | سرعت خواندن، اگر مدل پشتیبانی کند. |

:::tip
برای متن فارسی، کیفیت صدا را با نمونه واقعی محصول خود بسنجید. تلفظ نام برند، عددها، اختصارها و واژه‌های تخصصی می‌تواند بین صداها و مدل‌ها متفاوت باشد.
:::

## خروجی

خروجی معمولاً فایل صوتی است، نه JSON متنی. سرویس شما باید آن را:

- به کاربر stream کند.
- در storage امن ذخیره کند.
- یا به سیستم پخش صوتی محصول بدهد.

اگر فرمت خروجی برای محصول مهم است، آن را صریح با `response_format` تنظیم کنید و قبل از انتشار در مرورگرها یا اپلیکیشن‌های هدف آزمایش کنید.

## طراحی متن ورودی

متنی که برای تولید گفتار می‌فرستید باید خواندنی باشد، نه فقط قابل نمایش:

- جمله‌ها را کوتاه‌تر بنویسید.
- علامت‌گذاری را برای مکث طبیعی رعایت کنید.
- عددها و اختصارهای مهم را در صورت نیاز به شکل خواندنی بنویسید.
- متن خیلی طولانی را به بخش‌های کوتاه‌تر تقسیم کنید.

:::warning
از تولید صوت برای جعل هویت، تقلید صدای افراد بدون مجوز یا محتوای فریبنده استفاده نکنید. سیاست محصول خود را برای صدای مصنوعی، ذخیره فایل و رضایت کاربر روشن نگه دارید.
:::

## تفاوت با Speech to Text

| موضوع | Text to Speech | Speech to Text |
| --- | --- | --- |
| ورودی | متن | فایل صوتی |
| خروجی | فایل صوتی | متن |
| کاربرد | خواندن پاسخ و اعلان صوتی | پیاده‌سازی مکالمه یا پیام صوتی |

این دو API در یک محصول می‌توانند کنار هم قرار بگیرند، اما قرارداد و هزینه آن‌ها جداست.

## خطاهای رایج

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| مسیر در محیط شما فعال نیست | قابلیت صوتی فعال نشده است. | وضعیت فعال‌سازی را در فضای کاری بررسی کنید. |
| صدای انتخابی خطا می‌دهد | `voice` با مدل سازگار نیست. | فهرست صداهای مجاز همان مدل را بررسی کنید. |
| خروجی در دستگاه کاربر پخش نمی‌شود | فرمت صوتی پشتیبانی نمی‌شود. | فرمت رایج‌تری مثل `mp3` آزمایش کنید. |
| تلفظ فارسی ضعیف است | مدل یا صدا برای متن شما مناسب نیست. | چند صدا و مدل را با نمونه واقعی ارزیابی کنید. |

## جمع‌بندی

`Text to Speech` برای تبدیل متن به تجربه شنیداری است. متن ورودی را برای شنیدن طراحی کنید، مدل و صدا را با داده فارسی واقعی بسنجید و فایل صوتی خروجی را مثل دارایی رسانه‌ای حساس مدیریت کنید.
