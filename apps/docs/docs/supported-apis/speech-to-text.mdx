# Speech to Text

`Speech to Text` برای تبدیل فایل صوتی به متن استفاده می‌شود. این API در محصول‌هایی کاربرد دارد که باید مکالمه، پیام صوتی، جلسه یا تماس را به متن قابل جست‌وجو و قابل پردازش تبدیل کنند.

```text
POST /v1/audio/transcriptions
```

:::info
فعال‌بودن مسیرهای صوتی به نسخه و تنظیمات محیط گدارAI شما بستگی دارد. اگر این مسیر در فضای کاری شما فعال نیست، فعلاً لایه orchestration را در سرویس خودتان نگه دارید و برای فعال‌سازی مسیر رسمی با تیم گدارAI هماهنگ کنید.
:::

## چه زمانی استفاده کنیم؟

از `Speech to Text` استفاده کنید وقتی می‌خواهید:

- پیام صوتی کاربر را به متن تبدیل کنید.
- تماس‌های پشتیبانی را قابل جست‌وجو کنید.
- متن جلسه را برای خلاصه‌سازی به `Chat Completions` بدهید.
- فایل صوتی را به داده قابل پردازش در سیستم خود تبدیل کنید.

اگر هدف شما ترجمه گفتار به زبان دیگر است، [Audio Translation](/supported-apis/audio-translation) را ببینید. اگر هدف تولید فایل صوتی از متن است، [Text to Speech](/supported-apis/text-to-speech) مسیر جداگانه‌ای دارد.

## قرارداد رایج درخواست

وقتی مسیر در محیط شما فعال باشد، درخواست معمولاً با `multipart/form-data` ارسال می‌شود:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_GODARAI_TOKEN",
    base_url="https://YOUR_WORKSPACE.godarai.ir/v1",
)

with open("sample.wav", "rb") as audio:
    transcript = client.audio.transcriptions.create(
        model="openai:default:whisper-1",
        file=audio,
        language="fa",
        response_format="json",
    )

print(transcript.text)
```

مدل باید برای تبدیل گفتار به متن در فضای کاری شما مجاز باشد. شناسه مدل را از مدل‌های مجاز یا مدل مجازی بردارید، نه از حدس یا نمونه عمومی.

## فیلدهای رایج

| فیلد | کاربرد |
| --- | --- |
| `model` | شناسه مدل صوتی مجاز. |
| `file` | فایل صوتی ورودی. |
| `language` | زبان گفتار، اگر مدل پشتیبانی کند. |
| `prompt` | راهنمای کوتاه برای واژه‌های خاص یا زمینه، اگر مدل پشتیبانی کند. |
| `response_format` | فرمت پاسخ؛ مثل `json` یا فرمت‌های متنی دیگر، بسته به مدل. |

:::tip
اگر زبان فایل را می‌دانید، مقدار `language` را ارسال کنید. این کار معمولاً کیفیت تشخیص را بهتر و خطاهای زبان‌های نزدیک را کمتر می‌کند.
:::

## خروجی

خروجی ساده معمولاً متن پیاده‌شده را برمی‌گرداند:

```json
{
  "text": "سلام، این یک نمونه پیام صوتی برای آزمایش است."
}
```

در بعضی مدل‌ها یا فرمت‌ها، خروجی می‌تواند شامل زمان‌بندی، segment یا جزئیات بیشتر باشد. فقط به فیلدهایی تکیه کنید که مدل و مسیر فعال محیط شما واقعاً برمی‌گرداند.

## کیفیت فایل ورودی

کیفیت تبدیل گفتار به متن به فایل ورودی وابسته است. برای نتیجه بهتر:

- نویز پس‌زمینه را کم کنید.
- اگر ممکن است، از فرمت فشرده‌سازی شدید استفاده نکنید.
- زبان گفتار را مشخص کنید.
- فایل‌های طولانی را به بخش‌های قابل مدیریت تقسیم کنید.
- برای واژه‌های تخصصی، `prompt` کوتاه و دقیق بدهید.

:::warning
فایل صوتی می‌تواند شامل داده شخصی، اطلاعات مشتری یا مکالمه محرمانه باشد. قبل از ارسال، سیاست نگهداری، دسترسی و حذف فایل و متن پیاده‌شده را در اپلیکیشن خود روشن کنید.
:::

## تفاوت با Audio Translation

| موضوع | Speech to Text | Audio Translation |
| --- | --- | --- |
| هدف | تبدیل گفتار به متن همان زبان | ترجمه گفتار به متن زبانی دیگر |
| خروجی | transcript | متن ترجمه‌شده |
| کاربرد | جست‌وجو، خلاصه‌سازی، بایگانی | فهم محتوای صوتی زبان دیگر |

اگر فقط متن فارسی گفتار فارسی را می‌خواهید، `Speech to Text` انتخاب درست است.

## خطاهای رایج

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| مسیر در محیط شما در دسترس نیست | قابلیت صوتی فعال نشده است. | وضعیت فعال‌سازی فضای کاری را بررسی کنید. |
| خطای مدل | مدل برای STT مجاز یا سازگار نیست. | مدل صوتی مناسب انتخاب کنید. |
| کیفیت متن پایین است | فایل نویز دارد یا زبان اشتباه تشخیص داده شده است. | فایل تمیزتر، `language` و prompt کوتاه آزمایش کنید. |
| خطای اندازه یا فرمت فایل | فایل با محدودیت مدل سازگار نیست. | فایل را کوتاه‌تر یا به فرمت رایج‌تر تبدیل کنید. |

## جمع‌بندی

`Speech to Text` مسیر تبدیل صوت به متن قابل پردازش است. برای استفاده قابل اعتماد، مسیر فعال محیطتان را بررسی کنید، فایل تمیز بفرستید، زبان را مشخص کنید و متن خروجی را مثل داده حساس مدیریت کنید.
