# کلیدهای JSON

گاردریل `json_keys` وجود یا نبودن چند کلید مشخص را در سطح اول یک شیء JSON بررسی می‌کند. وقتی سیاست شما فقط درباره نام کلیدهاست، این نوع از [JSON Schema](/guardrails-json-schema) ساده‌تر و سریع‌تر فهمیده می‌شود.

## چه زمانی استفاده کنید؟

از این گاردریل برای این کارها استفاده کنید:

- اطمینان از وجود همه فیلدهای اصلی پاسخ.
- پذیرش پاسخ وقتی حداقل یکی از چند کلید وجود دارد.
- جلوگیری از برگشت کلیدهای ممنوع، مثل `debug` یا `internal_notes`.

## رفتار اجرایی

این نوع فقط از «اعتبارسنجی» (`operation: "validate"`) پشتیبانی می‌کند. کل متن باید یک شیء JSON معتبر باشد. آرایه، مقدار ساده، متن ترکیبی یا JSON داخل بلوک کد رد می‌شود.

«نحوه بررسی کلیدها» یکی از حالت‌های زیر است:

| عنوان | مقدار API | شرط قبولی |
| --- | --- | --- |
| همه کلیدها | `all` | همه کلیدهای واردشده در سطح اول وجود داشته باشند. مقدار پیش‌فرض است. |
| حداقل یکی | `any` | حداقل یکی از کلیدهای واردشده وجود داشته باشد. |
| هیچ‌کدام | `none` | هیچ‌کدام از کلیدهای واردشده وجود نداشته باشند. |

## تنظیمات

| عنوان | مقدار API | توضیح |
| --- | --- | --- |
| کلیدها | `keys` | هر خط یک نام کلید است. دست‌کم یک کلید لازم است. |
| نحوه بررسی کلیدها | `mode` | یکی از مقدارهای `all`، `any` یا `none`. |

## نمونه تعریف

نمونه زیر فقط وقتی پاسخ را می‌پذیرد که هر دو کلید `answer` و `sources` در سطح اول وجود داشته باشند:

```json
{
  "slug": "public-answer-keys",
  "name": "Public answer keys",
  "type": "json_keys",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "keys": ["answer", "sources"],
    "mode": "all"
  }
}
```

برای منع کلیدهای داخلی:

```json
{
  "keys": ["internal_notes", "debug"],
  "mode": "none"
}
```

## نمونه استفاده

```text
x-godarai-guardrails: {"llm_output_guardrails":["guardrails/public-answer-keys"]}
```

## بررسی نتیجه

اگر متن JSON معتبر نباشد، علت `Response is not valid JSON` ثبت می‌شود. اگر شرط کلیدها برقرار نباشد، علت `JSON keys validation failed` ثبت می‌شود.

## محدودیت‌ها

- فقط کلیدهای سطح اول بررسی می‌شوند. مقدارهایی مثل `user.email` مسیر تودرتو محسوب نمی‌شوند.
- مقدار و نوع کلید بررسی نمی‌شود. برای این کار از [JSON Schema](/guardrails-json-schema) استفاده کنید.
- نام کلیدها به بزرگی و کوچکی حروف حساس است.
- گاردریل خروجی با پاسخ جریانی پشتیبانی نمی‌شود.

## گام بعدی

- برای کنترل نوع فیلدها، [JSON Schema](/guardrails-json-schema) را بخوانید.
- برای خروجی ساخت‌یافته مدل، [Structured Outputs](/supported-apis/chat-completions/structured-outputs) را ببینید.
