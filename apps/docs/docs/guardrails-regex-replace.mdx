# جایگزینی با Regex

گاردریل `regex_replace` هر تطابق یک الگوی Regex را در متن جایگزین می‌کند. این نوع برای اصلاح مستقیم متن مناسب است؛ برای نمونه، یکسان‌سازی قالب شناسه‌ها یا ماسک‌کردن بخش مشخصی از متن.

اگر می‌خواهید تطابق باعث توقف درخواست یا پاسخ شود، از [Regex](/guardrails-regex) با «نوع اقدام» برابر «اعتبارسنجی» استفاده کنید.

## چه زمانی استفاده کنید؟

از این گاردریل برای این کارها استفاده کنید:

- ماسک‌کردن شناسه یا مقدار حساس با یک الگوی مشخص.
- یکسان‌سازی قالب داده پیش از ارسال به مدل.
- جایگزینی بخشی از متن با استفاده از گروه‌های Regex، مثل `$1`.

## رفتار اجرایی

این نوع فقط از «اصلاح محتوا» (`operation: "mutate"`) پشتیبانی می‌کند. گدارAI الگوی Regex را روی هر متن انتخاب‌شده اجرا می‌کند و همه تطابق‌ها را با «متن جایگزین» جایگزین می‌کند.

اگر تغییری انجام شود، وضعیت `mutated` و علت `Regex replacement applied` ثبت می‌شود.

## تنظیمات

| عنوان | مقدار API | توضیح |
| --- | --- | --- |
| الگوی Regex | `pattern` | یک Regex معتبر. این مقدار اجباری است. |
| متن جایگزین | `replacement` | متنی که به جای تطابق‌ها قرار می‌گیرد. مقدار پیشنهادی `[***]` است. |

این نوع با حساسیت به بزرگی و کوچکی حروف ذخیره می‌شود. اگر از API مستقیم استفاده می‌کنید، مقدار `case_sensitive` هم در `config` قابل ارسال است.

## نمونه تعریف

نمونه زیر عبارت‌هایی مثل `ticket 123456` یا `ticket-123456` را به قالب ثابت `TICKET-123456` تبدیل می‌کند:

```json
{
  "slug": "normalize-ticket",
  "name": "Normalize ticket IDs",
  "type": "regex_replace",
  "operation": "mutate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "pattern": "(?i)ticket[- ]([0-9]{6})",
    "replacement": "TICKET-$1",
    "case_sensitive": true
  }
}
```

## نمونه استفاده

برای اصلاح ورودی مدل:

```text
x-godarai-guardrails: {"llm_input_guardrails":["guardrails/normalize-ticket"]}
```

برای اصلاح پاسخ غیرجریانی مدل:

```text
x-godarai-guardrails: {"llm_output_guardrails":["guardrails/normalize-ticket"]}
```

## بررسی نتیجه

اگر متن تغییر کند، نتیجه در `guardrail_checks` با وضعیت `mutated` ثبت می‌شود. اگر هیچ تطابقی پیدا نشود، وضعیت `passed` است و متن بدون تغییر ادامه پیدا می‌کند.

## محدودیت‌ها

- این نوع فقط متن را تغییر می‌دهد و برای توقف تطابق طراحی نشده است.
- الگو روی هر بخش متنی جداگانه اجرا می‌شود.
- گاردریل آماده برای این نوع وجود ندارد؛ باید گاردریل اختصاصی بسازید.
- گاردریل خروجی با پاسخ جریانی پشتیبانی نمی‌شود.

## گام بعدی

- برای توقف تطابق‌ها، [Regex](/guardrails-regex) را با «اعتبارسنجی» استفاده کنید.
- برای ماسک‌کردن داده شخصی رایج، [PII پایه](/guardrails-pii-redaction) را ببینید.
