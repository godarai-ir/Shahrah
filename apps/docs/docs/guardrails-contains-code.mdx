# تشخیص کد

گاردریل `contains_code` وجود محتوای شبیه کد را در متن تشخیص می‌دهد. با این نوع می‌توانید کد را الزامی کنید، یا برعکس، جلوی تولید کد را در یک مسیر فقط متنی بگیرید.

## چه زمانی استفاده کنید؟

از این گاردریل برای این کارها استفاده کنید:

- الزام پاسخ مدل به داشتن نمونه کد.
- جلوگیری از تولید SQL، اسکریپت shell یا کد اجرایی در یک تجربه کاربری فقط متنی.
- محدودکردن بررسی به زبان‌هایی مثل `sql`، `python` یا `typescript`.

## رفتار اجرایی

این نوع فقط از «اعتبارسنجی» (`operation: "validate"`) پشتیبانی می‌کند.

«قاعده کد» یکی از حالت‌های زیر است:

| عنوان | مقدار API | شرط قبولی |
| --- | --- | --- |
| باید کد داشته باشد | `must_contain` | متن باید کد تشخیص‌پذیر داشته باشد. مقدار پیش‌فرض است. |
| نباید کد داشته باشد | `must_not_contain` | متن نباید کد تشخیص‌پذیر داشته باشد. |

گدارAI ابتدا fence سه‌تایی backtick را بررسی می‌کند. سپس برای زبان‌های شناخته‌شده، نشانه‌هایی مثل `select ... from`، `def`، `import`، `function`، `const`، `func`، `package`، `curl` و shebang را جست‌وجو می‌کند.

## تنظیمات

| عنوان | مقدار API | توضیح |
| --- | --- | --- |
| زبان‌های کد | `languages` | هر خط یک زبان است. اگر خالی بماند، `sql`، `python`، `typescript`، `javascript`، `go` و `shell` بررسی می‌شوند. |
| قاعده کد | `mode` | یکی از مقدارهای `must_contain` یا `must_not_contain`. |

## نمونه تعریف برای منع SQL

```json
{
  "slug": "no-sql-output",
  "name": "No SQL in output",
  "type": "contains_code",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "languages": ["sql"],
    "mode": "must_not_contain"
  }
}
```

## نمونه استفاده

```text
x-godarai-guardrails: {"llm_output_guardrails":["guardrails/no-sql-output"]}
```

## بررسی نتیجه

اگر شرط برقرار نباشد، علت `Code content validation failed` ثبت می‌شود. با «عدم عبور و لاگ»، مسیر متوقف می‌شود. با «عبور همراه با نشانه‌گذاری»، وضعیت `flagged` ثبت می‌شود و مسیر ادامه پیدا می‌کند.

## محدودیت‌ها

- تشخیص کد بر اساس نشانه‌های ساده است و تجزیه‌گر یا کامپایلر رسمی زبان نیست.
- واژه‌های شبیه کد در متن عادی ممکن است تطابق اشتباه بسازند.
- کدی که با قالب متفاوت نوشته شده باشد، ممکن است تشخیص داده نشود.
- برای زبان ناشناخته، فقط fence دارای برچسب همان زبان قابل تشخیص است.
- گاردریل خروجی با پاسخ جریانی پشتیبانی نمی‌شود.

## گام بعدی

- برای کنترل خروجی JSON، [JSON Schema](/guardrails-json-schema) یا [کلیدهای JSON](/guardrails-json-keys) را ببینید.
- برای کنترل عبارت‌های ثابت، [عبارت‌های مسدود](/guardrails-keyword-blocklist) را بخوانید.
