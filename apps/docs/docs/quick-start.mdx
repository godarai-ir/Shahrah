# شروع سریع گدارAI

این راهنما به شما کمک می‌کند در کمترین زمان، گدارAI را راه‌اندازی کنید، مدل‌های خود را متصل کنید و اولین درخواست را از طریق گیت‌وی ارسال کنید.

## 1. ثبت‌نام و ورود

ابتدا وارد محیط گدارAI شوید و حساب خود را فعال کنید. پس از تایید اطلاعات ورود، به داشبورد tenant منتقل می‌شوید.

> `جای خالی تصویر`
>
> اسکرین‌شات صفحه ورود یا صفحه خوش‌آمدگویی را اینجا قرار دهید.

## 2. افزودن حساب ارائه‌دهنده و مدل‌ها

برای استفاده از مدل‌ها، باید حداقل یک حساب ارائه‌دهنده اضافه کنید و مدل‌های قابل استفاده آن را فعال کنید.

مراحل کلی:

1. از داخل پنل tenant به صفحه `Provider Accounts` بروید.
2. یک ارائه‌دهنده مثل `OpenAI`، `Anthropic` یا سایر ارائه‌دهنده‌های پشتیبانی‌شده را انتخاب کنید.
3. اطلاعات دسترسی یا API Key را وارد کنید.
4. مدل‌هایی را که می‌خواهید در گیت‌وی در دسترس باشند فعال یا اضافه کنید.

> `جای خالی تصویر`
>
> اسکرین‌شات صفحه انتخاب ارائه‌دهنده و فرم افزودن حساب را اینجا قرار دهید.

### حساب ارائه‌دهنده چیست؟

حساب ارائه‌دهنده نماینده یک اتصال مستقل به یک vendor مدل است. می‌توانید برای یک ارائه‌دهنده چند حساب جداگانه داشته باشید و برای هر حساب، مجموعه متفاوتی از مدل‌ها را مدیریت کنید.

> `جای خالی تصویر`
>
> اسکرین‌شات لیست مدل‌ها یا صفحه افزودن مدل به حساب ارائه‌دهنده را اینجا قرار دهید.

## 3. آزمایش مدل‌ها در محیط محصول

بعد از اتصال مدل‌ها، بهتر است قبل از اتصال اپلیکیشن خود، صحت تنظیمات را داخل محیط محصول بررسی کنید. هدف این مرحله این است که مطمئن شوید:

- حساب ارائه‌دهنده درست ثبت شده است
- مدل موردنظر فعال است
- درخواست آزمایشی بدون خطا پاسخ می‌گیرد

> `جای خالی تصویر`
>
> اسکرین‌شات بخش تست یا playground محصول را اینجا قرار دهید.

## 4. اتصال از طریق کد

برای فراخوانی مدل‌ها از داخل کد، به این سه مقدار نیاز دارید:

- `Base URL` گیت‌وی
- `API Key` یا توکن دسترسی
- `Model ID` یا نام مدلی که می‌خواهید صدا بزنید

این مقادیر باید از داخل پنل tenant یا بخش مربوط به دسترسی و مدل‌ها برداشته شوند.

> `جای خالی تصویر`
>
> اسکرین‌شات بخشی که Base URL، API Key یا نمونه کد را نشان می‌دهد اینجا قرار دهید.

### نمونه با OpenAI SDK در Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_SHAHRAH_API_KEY",
    base_url="YOUR_SHAHRAH_GATEWAY_BASE_URL",
)
```

### نمونه با متغیر محیطی

```bash
export OPENAI_BASE_URL="YOUR_SHAHRAH_GATEWAY_BASE_URL"
export OPENAI_API_KEY="YOUR_SHAHRAH_API_KEY"
```

پس از تنظیم این مقادیر، می‌توانید درخواست‌های OpenAI-compatible خود را از طریق گدارAI ارسال کنید.

## 5. قدم بعدی

بعد از راه‌اندازی اولیه، معمولاً این مراحل ارزش انجام دارند:

1. ساخت `Personal Access Token` برای توسعه‌دهندگان
2. تعریف `Virtual Model` برای داشتن یک alias پایدار
3. تنظیم policyهای مصرف، محدودیت و دسترسی
4. بررسی لاگ‌ها و متریک‌ها برای اعتبارسنجی ترافیک واقعی
