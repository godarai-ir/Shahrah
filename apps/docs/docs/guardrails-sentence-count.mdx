# محدودیت تعداد جمله

گاردریل `sentence_count` بررسی می‌کند تعداد جمله‌های هر متن، داخل بازه‌ی مجاز باشد. این گاردریل برای محدودکردن طول پرامپت یا الزام پاسخ‌های کوتاه و چندجمله‌ای مناسب است.

## چه زمانی استفاده کنیم؟

- ردکرکردن پرامپت‌های بیش از حد طولانی بر اساس جمله
- الزام پاسخ به حداقل یک جمله
- محدودکردن پاسخ مدل به تعداد مشخصی جمله

## رفتار اجرایی

این نوع فقط از `operation: "validate"` پشتیبانی می‌کند. پایان جمله با یکی از نویسه‌های `.`, `!`, `?`, `؟` یا `۔` تشخیص داده می‌شود. اگر بعد از آخرین علامت، متن حرف یا عدد داشته باشد، آن بخش هم یک جمله حساب می‌شود.

هر متن انتخاب‌شده جداگانه شمرده می‌شود؛ توجه داشته باشید که اگر پارامتر scope را برابر `all` قرار می‌دهید، مجموع جمله‌های پیام‌ها ملاک نیست و هر پیام مستقلا باید داخل بازه باشد.

## تنظیمات

| فیلد | نوع | اجباری | توضیح |
| --- | --- | --- | --- |
| `min` | `integer` | حداقل یکی از `min` یا `max` | حداقل تعداد مجاز؛ صفر یا بیشتر. |
| `max` | `integer` | حداقل یکی از `min` یا `max` | حداکثر تعداد مجاز؛ صفر یا بیشتر. |

اگر هر دو را بدهید، `min` باید کوچک‌تر یا مساوی `max` باشد.

## نمونه تعریف

```json
{
  "slug": "max-three-sentences",
  "name": "At most three sentences",
  "type": "sentence_count",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "min": 1,
    "max": 3
  }
}
```

## نمونه استفاده

```text
x-godarai-guardrails: {"llm_output_guardrails":["guardrails/max-three-sentences"]}
```

## محدودیت‌ها

- تشخیص جمله از قاعده‌ی رایج زبان و بر اساس چک نویسه‌های `.`, `!`, `?`, `؟` یا `۔`  در پایان جمله انجام می‌شود و ساختار زبانی را تحلیل نمی‌کند.
- نقطه داخل غبارت خلاصه شده (abbreviation) یا عدد اعشاری می‌تواند مرز جمله شمرده شود.
- برای استفاده از این گاردریل در خروجی مدل، باید از پاسخ non-stream استفاده کنید.
