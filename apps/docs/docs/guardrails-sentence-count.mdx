# تعداد جمله

گاردریل `sentence_count` بررسی می‌کند تعداد جمله‌های هر متن داخل بازه مجاز باشد. این نوع برای کوتاه نگه‌داشتن پاسخ مدل، یا جلوگیری از ورودی‌های خیلی بلند، کاربرد دارد.

## چه زمانی استفاده کنید؟

از این گاردریل برای این کارها استفاده کنید:

- محدودکردن پاسخ مدل به چند جمله مشخص.
- الزام پاسخ به حداقل یک جمله.
- متوقف‌کردن ورودی‌هایی که با تعداد جمله زیاد، مسیر گفتگو را از کنترل خارج می‌کنند.

اگر محدودیت شما به طول دقیق‌تر متن مربوط است، [تعداد کلمه](/guardrails-word-count) یا [تعداد کاراکتر](/guardrails-character-count) مناسب‌تر است.

## رفتار اجرایی

این نوع فقط از «اعتبارسنجی» (`operation: "validate"`) پشتیبانی می‌کند. پایان جمله با یکی از علامت‌های `.`, `!`, `?`, `؟` یا `۔` تشخیص داده می‌شود. اگر پس از آخرین علامت، متن هنوز حرف یا عدد داشته باشد، آن بخش هم یک جمله حساب می‌شود.

هر متن جداگانه بررسی می‌شود. اگر محدوده اجرا `all` باشد، مجموع جمله‌های چند پیام ملاک نیست؛ هر پیام باید جداگانه داخل بازه باشد.

## تنظیمات

| عنوان | مقدار API | توضیح |
| --- | --- | --- |
| حداقل | `min` | حداقل تعداد جمله مجاز. مقدار باید صفر یا بیشتر باشد. |
| حداکثر | `max` | حداکثر تعداد جمله مجاز. مقدار باید صفر یا بیشتر باشد. |

باید دست‌کم یکی از «حداقل» یا «حداکثر» را وارد کنید. اگر هر دو را وارد می‌کنید، حداقل باید کوچک‌تر یا برابر حداکثر باشد.

## نمونه تعریف

```json
{
  "slug": "max-three-sentences",
  "name": "At most three sentences",
  "type": "sentence_count",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "min": 1,
    "max": 3
  }
}
```

## نمونه استفاده

برای کنترل پاسخ غیرجریانی مدل:

```text
x-godarai-guardrails: {"llm_output_guardrails":["guardrails/max-three-sentences"]}
```

## بررسی نتیجه

اگر تعداد جمله بیرون از بازه باشد، علت `sentence count is outside allowed range` ثبت می‌شود. با «عدم عبور و لاگ»، پاسخ یا درخواست متوقف می‌شود. با «عبور همراه با نشانه‌گذاری»، فقط وضعیت `flagged` ثبت می‌شود.

## محدودیت‌ها

- این گاردریل ساختار زبانی جمله را تحلیل نمی‌کند؛ فقط علامت‌های پایان جمله را می‌شمارد.
- نقطه داخل مخفف یا عدد اعشاری ممکن است مرز جمله شمرده شود.
- گاردریل خروجی با پاسخ جریانی پشتیبانی نمی‌شود.

## گام بعدی

- برای محدودیت بر اساس کلمه، [تعداد کلمه](/guardrails-word-count) را ببینید.
- برای سقف دقیق‌تر طول متن، [تعداد کاراکتر](/guardrails-character-count) را بخوانید.
