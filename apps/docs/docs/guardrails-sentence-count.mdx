# تعداد جمله

گاردریل `sentence_count` بررسی می‌کند تعداد جمله‌های هر متن داخل بازه مجاز باشد. این نوع برای پاسخ‌هایی مناسب است که باید از نظر تجربه کاربری کوتاه، قابل خواندن و قابل پیش‌بینی بمانند؛ برای نمونه پاسخ خلاصه، پیام راهنمای کاربر یا توضیح کوتاه در محصول.

:::info
این گاردریل طول متن را با شمارش جمله کنترل می‌کند، نه با شمارش توکن. برای کنترل هزینه یا پنجره زمینه مدل، گزارش مصرف و محدودیت‌های توکن را جداگانه بررسی کنید.
:::

## چه زمانی استفاده کنید؟

از `sentence_count` برای این کارها استفاده کنید:

- محدودکردن پاسخ مدل به چند جمله مشخص.
- الزام پاسخ به حداقل یک جمله.
- متوقف‌کردن ورودی‌هایی که با تعداد جمله زیاد، مسیر گفتگو را از کنترل خارج می‌کنند.

اگر محدودیت شما به طول دقیق‌تر متن مربوط است، [تعداد کلمه](/guardrails-word-count) یا [تعداد کاراکتر](/guardrails-character-count) مناسب‌تر است.

## رفتار اجرایی

این نوع فقط از «اعتبارسنجی» (`operation: "validate"`) پشتیبانی می‌کند. پایان جمله با یکی از علامت‌های `.`, `!`, `?`, `؟` یا `۔` تشخیص داده می‌شود. اگر پس از آخرین علامت، متن هنوز حرف یا عدد داشته باشد، آن بخش هم یک جمله حساب می‌شود.

هر متن جداگانه بررسی می‌شود. اگر محدوده اجرا `all` باشد، مجموع جمله‌های چند پیام ملاک نیست؛ هر پیام باید جداگانه داخل بازه باشد.

## تنظیمات

| عنوان UI | مقدار API | توضیح |
| --- | --- | --- |
| حداقل | `min` | حداقل تعداد جمله مجاز. مقدار باید صفر یا بیشتر باشد. |
| حداکثر | `max` | حداکثر تعداد جمله مجاز. مقدار باید صفر یا بیشتر باشد. |

باید دست‌کم یکی از «حداقل» یا «حداکثر» را وارد کنید. اگر هر دو را وارد می‌کنید، حداقل باید کوچک‌تر یا برابر حداکثر باشد.

:::tip
برای پاسخ‌های کوتاه محصولی، معمولاً `min: 1` و `max: 3` نقطه شروع خوبی است. بعد از مشاهده پاسخ‌های واقعی، بازه را با لحن و نیاز محصول خودتان تنظیم کنید.
:::

## نمونه تعریف

```json
{
  "slug": "max-three-sentences",
  "name": "At most three sentences",
  "type": "sentence_count",
  "operation": "validate",
  "enforcement": "enforce",
  "enabled": true,
  "config": {
    "min": 1,
    "max": 3
  }
}
```

## نمونه استفاده

برای کنترل پاسخ غیرجریانی مدل:

```text
x-godarai-guardrails: {"llm_output_guardrails":["guardrails/max-three-sentences"]}
```

:::warning
گاردریل خروجی با پاسخ جریانی پشتیبانی نمی‌شود. اگر `stream: true` دارید، یا پاسخ جریانی را غیرفعال کنید یا این گاردریل را روی ورودی مدل به کار ببرید.
:::

## بررسی نتیجه

اگر تعداد جمله بیرون از بازه باشد، علت `sentence count is outside allowed range` ثبت می‌شود.

| شیوه اعمال | رفتار |
| --- | --- |
| عدم عبور و لاگ | پاسخ یا درخواست متوقف می‌شود. |
| عبور همراه با نشانه‌گذاری | وضعیت `flagged` ثبت می‌شود و مسیر ادامه پیدا می‌کند. |

## محدودیت‌ها

- این گاردریل ساختار زبانی جمله را تحلیل نمی‌کند؛ فقط علامت‌های پایان جمله را می‌شمارد.
- نقطه داخل مخفف یا عدد اعشاری ممکن است مرز جمله شمرده شود.
- متن بدون نشانه پایان جمله، اگر حرف یا عدد داشته باشد، یک جمله حساب می‌شود.

## پرسش‌های پرتکرار

### آیا جمله‌های فارسی و انگلیسی هر دو شمرده می‌شوند؟

بله، شمارش بر اساس علامت‌های پایان جمله و وجود حرف یا عدد است. با این حال، دقت آن به نشانه‌گذاری متن بستگی دارد.

### آیا این گاردریل برای محدودیت هزینه کافی است؟

خیر. تعداد جمله با تعداد توکن یکی نیست. برای هزینه از [کنترل مصرف و هزینه](/guides/budget-limiting) و سنجه‌های مصرف استفاده کنید.

## گام بعدی

- برای محدودیت بر اساس کلمه، [تعداد کلمه](/guardrails-word-count) را ببینید.
- برای سقف دقیق‌تر طول متن، [تعداد کاراکتر](/guardrails-character-count) را بخوانید.
