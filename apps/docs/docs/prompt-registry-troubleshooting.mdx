# عیب‌یابی رجیستری پرامپت

این صفحه خطاها و وضعیت‌های رایج رجیستری پرامپت را توضیح می‌دهد؛ از ذخیره نسخه تا رندر متغیرها و اجرای نسخه با `prompt_version_fqn`.

## خطاهای ساخت و ذخیره

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| `invalidName` یا پیام نام نامعتبر | نام پرامپت شامل کاراکتر غیرمجاز است. | فقط از حرف انگلیسی، عدد، خط تیره و زیرخط استفاده کنید. |
| `messages must not be empty` | هیچ پیام راهنما، کاربر یا دستیار ذخیره نشده است. | دست‌کم یک پیام به قالب پرامپت اضافه کنید. |
| `modelRequired` | در UI مدلی انتخاب نشده است. | یک مدل یا مدل مجازی قابل استفاده در گدارAI انتخاب کنید. |
| `prompt already exists` | پرامپتی با همین نام در فضای کاری وجود دارد. | نام دیگری انتخاب کنید یا نسخه جدید همان پرامپت را بسازید. |
| `invalid prompt payload` | ساختار مانیفست یا تنظیمات معتبر نیست. | Spec را با فیلدهای مجاز بررسی کنید و دوباره ذخیره کنید. |

:::tip
برای تغییر پرامپت موجود، به‌جای ساخت پرامپت هم‌نام، از «ویرایش نسخه آخر» و «ذخیره نسخه جدید» استفاده کنید.
:::

## خطاهای متغیر و رندر

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| `missing prompt variable: name` | متغیر `{{name}}` در نسخه هست اما مقدار آن ارسال نشده است. | مقدار را در `prompt_variables` بفرستید. |
| متغیر در UI دیده نمی‌شود | قالب متغیر معتبر نیست. | از قالبی مثل `{{customer_name}}` استفاده کنید. |
| مقدار جایگذاری نمی‌شود | نام متغیر در پرامپت و درخواست متفاوت است. | نام‌ها را دقیقاً یکسان کنید. |
| `renderVariablesMissing` | در تست آزمایشی مقدار لازم وارد نشده است. | مقدار همه متغیرهای ورودی را در UI پر کنید. |

نمونه مقدار درست:

```json
{
  "prompt_variables": {
    "customer_name": "سارا",
    "issue": "تاخیر در ارسال"
  }
}
```

## خطاهای FQN

| پیام | معنی | راه‌حل |
| --- | --- | --- |
| `prompt_version_fqn must start with chat_prompt` | نوع FQN درست نیست. | مقدار باید با `chat_prompt:` شروع شود. |
| `prompt_version_fqn must include a version` | شماره نسخه در FQN نیست. | قالب `chat_prompt:{tenant_slug}/{prompt_name}:{version}` را کامل بفرستید. |
| `prompt_version_fqn version must be a positive integer` | نسخه عدد مثبت نیست. | نسخه‌ای مثل `:1` یا `:3` بفرستید. |
| `prompt not found` | نسخه یا پرامپت در فضای کاری پیدا نشده است. | FQN، فضای کاری و حذف‌نشدن پرامپت را بررسی کنید. |

نمونه FQN درست:

```text
chat_prompt:acme/support_reply:3
```

:::warning
FQN به فضای کاری وابسته است. FQN یک محیط را در محیط دیگر کپی نکنید، مگر مطمئن باشید همان پرامپت و نسخه در آن محیط وجود دارد.
:::

## خطاهای اجرا از درگاه

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| `Prompt store is not configured` | سرویس رجیستری برای محیط شما آماده نیست. | با مالک محیط یا پشتیبانی گدارAI هماهنگ کنید. |
| `Model is required` | نسخه مدل ندارد و درخواست هم `model` نفرستاده است. | در نسخه مدل ذخیره کنید یا `model` را در درخواست بفرستید. |
| `Model access denied or unsupported for chat completions` | مدل انتخاب‌شده برای توکن شما مجاز نیست یا از Chat Completions پشتیبانی نمی‌کند. | مدل مجاز دیگری انتخاب کنید یا دسترسی مدل را بررسی کنید. |
| پاسخ با نسخه مورد انتظار فرق دارد | درخواست `model` یا پیام اضافه رفتار نسخه را تغییر داده است. | FQN، `model` و `messages` ارسالی هنگام اجرا را بررسی کنید. |

## خطاهای تنظیمات پیشرفته

| نشانه | علت محتمل | راه‌حل |
| --- | --- | --- |
| `output guardrails require streaming to be disabled` | گاردریل خروجی همراه `stream: true` تنظیم شده است. | `stream` را غیرفعال کنید یا گاردریل خروجی را حذف کنید. |
| `cache.type must be simple or smart` | نوع کش معتبر نیست. | مقدار `simple` یا `smart` بفرستید. |
| `cache.ttl must be at least 1` | مقدار TTL مثبت نیست. | عدد صحیح مثبت وارد کنید. |
| `cache.similarity_threshold must be between 0.8 and 1` | آستانه کش هوشمند خارج از بازه است. | مقدار بین `0.8` و `1` انتخاب کنید. |
| `structured_output.schema is required for json_schema format` | خروجی ساخت‌یافته از نوع `json_schema` است اما schema ندارد. | یک JSON Schema معتبر وارد کنید. |

## چطور سریع تشخیص بدهیم مشکل از کجاست؟

1. FQN را با قالب `chat_prompt:{tenant_slug}/{prompt_name}:{version}` بررسی کنید.
2. مطمئن شوید همه متغیرهای نسخه در `prompt_variables` مقدار دارند.
3. اگر مدل در درخواست می‌فرستید، بدانید همان مدل برای اجرا استفاده می‌شود.
4. اگر کش یا گاردریل لازم دارید، سرآیندهای مربوط را در درخواست بفرستید.
5. گزارش رخدادها را با فیلدهای `prompt_fqn` و `prompt_version` بررسی کنید.
